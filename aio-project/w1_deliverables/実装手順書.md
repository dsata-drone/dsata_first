# W1成果物 実装手順書（llms.txt＋構造化データ）

作成: 2026-07-19 / 担当: レイ（実装コード）・ジン（手順統括）
対象: alux-follow.com / follow.ne.jp

## 納品物一覧
| ファイル | 配置先 |
|---|---|
| `llms.txt_alux-follow.com` | `https://alux-follow.com/llms.txt` としてルート直下に配置（ファイル名は `llms.txt` にリネーム） |
| `llms.txt_follow.ne.jp` | `https://follow.ne.jp/llms.txt` として同上 |
| `structured_data_alux-follow.com.html` | 各ページの `</head>` 直前に該当ブロックを貼り付け |

## 手順（alux-follow.com）
1. `llms.txt_alux-follow.com` を `llms.txt` にリネームしてサイトルートにアップロード
   - 確認: ブラウザで `https://alux-follow.com/llms.txt` を開いてそのまま表示されること
2. 構造化データの `[要確認]` 箇所（ロゴ画像・製品画像・税込価格）を実際の値に置き換える
3. ①②をトップページ、③を codingdrone ページ、④を codingrider ページ、⑤をFAQページに貼る
4. 検証: [Googleリッチリザルトテスト](https://search.google.com/test/rich-results) に各ページURLを入れてエラー0を確認
5. Google Search Console でトップ＋製品2ページのインデックス再登録をリクエスト

## 手順（follow.ne.jp）
1. `llms.txt_follow.ne.jp` を `llms.txt` にリネームしてサイトルートにアップロード
2. Organization構造化データ（①）をトップページに貼る（follow.ne.jp用に `url` はそのまま使える）

## 注意事項
- **JSレンダリング問題（7/16監査で指摘）**: alux-follow.com が本文をJSで描画している場合、
  AIクローラーは本文を読めないことがある。llms.txt はその保険になるが、
  恒久対応としてSSR/プリレンダリングの検討をW2以降で行う
- 価格をサイトに掲載していない場合は `offers` ブロックごと削除する（虚偽・空の価格は逆効果）
- FAQの雛形3問は必ず実ページの記載内容と一致させること（ページにない内容を構造化データだけに書くとスパム判定リスク）
