お世話になっております。株式会社followです。

弊社公式サイト2件に対する、AI検索最適化(AIO)のための軽微な実装作業をお願いしたく、
内容を以下にまとめました。作業ファイルは弊社で作成済みのため、**設置・貼り付け・検証が主な作業**です。

## 1. 対象サイト
| サイト | 役割 |
|---|---|
| https://alux-follow.com/ | 製品サイト(ALUX PROGRAMMING) |
| https://follow.ne.jp/ | コーポレートサイト |

## 2. 作業の目的(背景)
ChatGPT・Perplexity・Google AIオーバービュー等の「AI検索」に弊社製品が引用されやすくするため、
①AI向けサイト案内ファイル(llms.txt)の設置と、②検索エンジン向け構造化データ(JSON-LD)の実装を行います。

## 3. 添付ファイル(弊社作成済み)
| ファイル | 内容 |
|---|---|
| `llms.txt_alux-follow.com` | alux-follow.com 用の llms.txt |
| `llms.txt_follow.ne.jp` | follow.ne.jp 用の llms.txt |
| `structured_data_alux-follow.com.html` | 構造化データ6ブロック(①Organization ②WebSite ③④Product ⑤FAQ ⑥NewsArticle) |

## 4. 作業内容
### 4-1. llms.txt の設置(2サイト)
1. `llms.txt_alux-follow.com` を **`llms.txt` にリネーム**し、alux-follow.com のドキュメントルート直下にアップロード
2. `llms.txt_follow.ne.jp` も同様に follow.ne.jp のルート直下へ
3. 確認: ブラウザで `https://alux-follow.com/llms.txt` と `https://follow.ne.jp/llms.txt` を開き、
   テキストがそのまま表示されること(Content-Type: text/plain 推奨)

### 4-2. 構造化データの貼り付け(alux-follow.com)
添付HTMLファイル内の各ブロックを、以下のページの `</head>` 直前に貼り付けてください。
| ブロック | 貼り付け先ページ |
|---|---|
| ① Organization + ② WebSite | トップページ |
| ③ Product(コーディングドローン) | /product/codingdrone |
| ④ Product(コーディングライダー) | /product/codingrider |
| ⑤ FAQPage | FAQ・よくある質問ページ(存在する場合のみ) |
| ⑥ NewsArticle | お知らせ記事テンプレート(CMS対応可能な場合のみ) |

### 4-3. プレースホルダの値確定(重要)
ファイル内に `[要確認]` と記載した箇所があります。実サイトの値に置き換えてください。
- ロゴ画像・製品画像の実URL
- 製品の税込価格 → **サイトに価格を掲載していない場合は `offers` ブロックごと削除**(空の価格は逆効果のため)
- ⑤FAQの質問・回答は、**実際のFAQページの記載と一致するよう編集**
  (ページに書いていない内容を構造化データだけに入れることはスパム判定リスクがあるため厳禁)

### 4-4. コーポレートサイト(follow.ne.jp)
- ①Organization ブロックのみトップページの `</head>` 直前に貼り付け

### 4-5. 検証(納品前チェック)
1. [Googleリッチリザルトテスト](https://search.google.com/test/rich-results) に対象4ページのURLを入力し、**エラー0件**を確認
2. 各ページのソース表示で JSON-LD が1回だけ出力されていること(重複貼り付けがないこと)
3. Google Search Console で、トップ+製品2ページのインデックス再登録(URL検査→リクエスト)
   ※Search Console 未設定の場合はご相談ください(下記オプション)

## 5. ご確認・ご相談事項
- alux-follow.com が本文をJavaScriptで描画している場合、構造化データは**サーバー出力のHTMLに含める**形で
  実装してください(タグマネージャ経由の後入れはAIクローラーに読まれない可能性があります)
- CMS・ホスティングの仕様上ルート直下にファイルを置けない場合は、事前にご連絡ください
