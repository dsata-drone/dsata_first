## 製品ラインアップ(価格は税込・カタログ時点)

### コーディングドローン — ¥37,920
- 対象: 小学生〜中学生
- **CES 2025 イノベーションアワード受賞**(コーディングドローン、ドローンゲームプラットフォーム部門)
- **世界初**: コントローラー不使用、コーディングカードのみで飛行するアンプラグド方式
- 操作: カードコーディング(カラーセンサーで色認識)/ モーションコーディング(傾き)/ Scratch / Python
- 機能: オートホバリング、障害物回避
- スペック: 133.8×138.5×34.8mm / 54.8g(バッテリー込) / 3.7V 530mAh / 飛行約8分 / 充電約60分 /
  最大2.5m/s(約9km/h) / 2.4GHz RF / 飛行距離 最大100m・推奨50m
- センサー: 6軸姿勢制御・気圧・カラー・障害物・IRレンジ・オプティカルフロー

### コーディングライダー — ¥23,760
- 対象: 中学生〜高校生
- 部品ごとの修理・交換が可能な**モジュール構造**、360度セーフネットガード(人に当たっても怪我しにくい)
- **干渉防止システムで複数台の編隊飛行が可能**(大人数授業向き)。1台のPCで複数台同時飛行可
- 操作: Scratch / Python / キーボードフライト / ジェスチャー認識フライト / モーション認識フライト(PCカメラ)
- 機能: オートホバリング、自動離着陸
- スペック: 135×135×43mm / 39g(バッテリー込) / 3.7V 300mAh / 飛行約5〜6分 / 充電約40分 /
  最大2.5m/s / 2.4GHz RF / 飛行距離 最大100m・推奨50m
- センサー: 6軸姿勢制御・気圧・IRレンジ・オプティカルフロー

### VINU(ビヌ) — ¥38,400
- 対象: 小学生(幼児からのアンプラグド学習にも)
- 正式名: Visualized Interesting New type Unplugged coding robot
- **CES 2024 ロボティクス部門イノベーションアワード受賞** / **Bett AWARDS 2024 ファイナリスト**
- **世界初のLCDモニター搭載アンプラグドロボット**。PC・インターネット・Wi-Fi接続不要
- 200種類以上の創意融合型コンテンツ(数学・英語・美術・音楽など教科と組み合わせ可)
- 5種類のセンサー(タッチ・傾き・距離・カラー等)、5種類のVINUブロック(出力・制御・入力・グリッド・モーター)
- スペック: 50×70×40mm / 121g / バッテリー1,000mA
- レベル別教材あり(**教材は別売り**)
