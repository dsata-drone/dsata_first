# 04. メンバー・スキーマ（自分のメンバーの入れ方）

**このテンプレにメンバーは含まれていません。** ここの仕様を見て、受け取った側が
自分のチームを `TEAM = [ ... ]` に定義してください。1人 = 1オブジェクト。

## 1件のフィールド
```js
{
  room: "ROOM 01",         // 所属部屋。ROOMS(01)の name と完全一致させる
  name: "（表示名）",       // office_state.json の name と一致させる主キー
  role: "肩書き・役割",     // ステータス表に出る説明
  task: "初期タスク",        // 起動直後の作業内容（JSONで上書きされる）
  load: 0.8,                // 稼働率0〜1。作業/休憩の長さ演出（03参照）
  hair:  "#4a3020",         // 髪の色
  shirt: "#2e3440",         // 上衣の色
  pants: "#20242e",         // 下衣の色
  acc:  ["tie:#c04a3e"],    // 持ち物・アクセサリ（複数可、下記）
  desk: {x:3, y:46},        // 机の左上座標（部屋矩形の内側に）
  door: 53,                 // 出入りに使うドアX（DOORS=53/158/263 から）
  pc:   "dual",             // 任意。モニタ種別（下記）。省略で通常デスク
  idle: true                // 任意。常時待機（最初から休憩室）にする場合 true
}
```

## アクセサリ `acc`（職業感を出す小物）
配列で複数指定可。色が要るものは `種類:#色` 形式。
```
glasses      … メガネ
sunglasses   … サングラス
cap:#色      … キャップ
beret:#色    … ベレー帽
headphones:#色 … ヘッドホン
tie:#色      … ネクタイ
mustache     … 口ひげ
```
例：`acc:["glasses","tie:#6a3a9e"]`（メガネ＋紫ネクタイ）

## モニタ種別 `pc`（机の上の画面を職種で変える）
省略すると通常デスク。指定すると天板・画面が変化。
```
dual    … デュアルモニタ（エンジニア/アナリスト系）
design  … デザイン用（縦長 or ペンタブ感）
edit    … 動画編集用
sns     … SNS/スマホ運用
trader  … 情報端末（複数画面）
```

## 配置のルール（破ると机がはみ出る/消える）
1. `room` は `ROOMS` の `name` と完全一致。
2. `desk.x/y` は所属部屋の矩形内に。上3段は高さ78か110、下2段は72。1部屋に複数机を置くときは
   `x` を約53、`y` を約48ずつずらすと重ならない（例：`{x:3,y:46}` と `{x:56,y:46}`、下段は `{x:3,y:158}` など）。
3. `door` は所属する列（左=53/中=158/右=263）に合わせる。
4. `name` は `office_state.json` で参照する主キー。**後から変えると連携が切れる**ので最初に確定させる。

## 記入テンプレ（コピーして使う）
```js
const TEAM = [
  // { room:"ROOM 01", name:"", role:"", task:"", load:.8,
  //   hair:"#4a3020", shirt:"#2e3440", pants:"#20242e",
  //   acc:["tie:#c04a3e"], desk:{x:3,y:46}, door:53 },
  //
  // …自分のメンバーをここに追加…
];
```
> `TEAM` が空でもオフィスの部屋・内装は描画される（人がいない状態）。
> 1人ずつ足して、ブラウザを再読み込みして位置を確認していくのが安全。

## 色の付け方のコツ
- 髪・服・パンツはピクセルアートなので、彩度をやや抑えた中間色が馴染む。
- 同じ部屋のメンバーは服色を少し散らすと見分けやすい。
- ダーク部屋（ブレイン/AI LAB）に置くなら、服はやや明るめにするとシルエットが埋もれない。
