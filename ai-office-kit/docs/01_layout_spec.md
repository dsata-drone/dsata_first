# 01. レイアウト仕様

## 座標系
- 論理キャンバス `W=384 × H=584`。内部解像度スケール `S=2`（描き込み用）。
- 描画は「論理座標 → ×2 実ピクセル」。ピクセルアート維持のため `imageSmoothingEnabled=false`。
- 擬似3/4ビュー（壁に上面キャップ＋高さのある正面＋巾木＋落ち影）。

## フロア構造（縦に5フロア）
上から順に、廊下（WALK_Y）で区切られた5段構成。

| 廊下定数 | Y | 区切るフロア |
|---|---|---|
| `WALK_Y` | 132 | 1階（row1/row2）用 |
| `WALK_Y2` | 274 | 2階（法務/契約/経理）用 |
| `WALK_Y3` | 386 | 3階（ブレイン）用 |
| `WALK_Y4` | 490 | 4階（AI LAB）用 |

その他の基準線：`WALL_Y=30`, `BASE_Y=34`。
右端は休憩室：`BREAK_X=322`, `BREAK_IN=336`。机幅 `DESK_W=46`。

## 部屋定義 `ROOMS`
各部屋は矩形＋2色（床グラデ）＋名前。座標は `{x,y,w,h}`（論理座標・左上原点）。

```js
const ROOMS=[
  {x:0,  y:34, w:105,h:78, c1:"#8093d8",c2:"#7486ca", name:"ROOM 01"},
  {x:105,y:34, w:105,h:78, c1:"#72c2a8",c2:"#66b49b", name:"会議室"},
  {x:210,y:34, w:106,h:78, c1:"#a48ad8",c2:"#977fc9", name:"ROOM 02"},
  {x:0,  y:146,w:105,h:110,c1:"#e08cb0",c2:"#d180a3", name:"ROOM 03"},
  {x:105,y:146,w:105,h:110,c1:"#7fc46e",c2:"#72b562", name:"ROOM 04"},
  {x:210,y:146,w:106,h:110,c1:"#e09a5e",c2:"#d18d52", name:"ROOM 05"},
  {x:0,  y:290,w:105,h:78, c1:"#7a86c0",c2:"#6e7ab2", name:"ROOM 06"},
  {x:105,y:290,w:105,h:78, c1:"#6fb2b8",c2:"#63a4aa", name:"ROOM 07"},
  {x:210,y:290,w:106,h:78, c1:"#c0a85e",c2:"#b29a52", name:"ROOM 08"},
  {x:0,  y:402,w:316,h:72, c1:"#2b3042",c2:"#262b3a", name:"LAB 01"}, // 大部屋・ダーク内装(司令室風)
  {x:0,  y:508,w:316,h:72, c1:"#4a4468",c2:"#443f60", name:"LAB 02"}, // 大部屋・ラボ内装
];
```
> テンプレHTML（`ai_office_template.html`）はこの中立名（ROOM 01〜08 / 会議室 / LAB 01・02 / 休憩室）で出荷済み。`name` を自分の部門名に書き換えるだけで使える。
> **注意**: `ROOMS` の `name` を変えたら、画面ラベルを描く `signPlate(...,"ROOM 01")` の文字列も同じ名前に合わせること（`01`末尾のチェックリスト参照）。
- 上3段は横3部屋（幅105/105/106）。ブレインとAI LABは横一列の大部屋（幅316）。
- **部屋名は自由に変えてよい**。ただし `TEAM` の各メンバーの `room` と**文字列一致**させること（一致しないと机が置かれない）。

## ドア `DOORS`
廊下からの入口X座標。3列レイアウトに対応。
```js
const DOORS=[53,158,263];  // 左室/中室/右室
```
各メンバーは `door:` にこのいずれかを指定して、席⇄休憩室の歩行経路に使う。

## 休憩室スポット `SPOTS`
12時間以上稼働のないキャラや常時待機キャラが移動する休憩位置（右端 x>322）。
```js
const SPOTS=[
  {x:342,y:93, pose:"sit",  dir:"down", taken:false},
  {x:360,y:93, pose:"sit",  dir:"down", taken:false},
  {x:354,y:172,pose:"lie",  dir:"down", taken:false}, // 寝そべり
  {x:336,y:206,pose:"sit",  dir:"right",taken:false},
  {x:368,y:206,pose:"sit",  dir:"left", taken:false},
  {x:336,y:52, pose:"stand",dir:"up",   taken:false},
];
```
- `pose`: `sit / lie / stand`。`taken` は実行時に埋まり具合を管理（初期 false）。
- スポット数 = 同時に休憩できる人数の上限。増やしたいなら要素を足す。

## 机・座席の自動計算
メンバーの `desk:{x,y}` を起点に、座席とラベルは自動配置。
- 座席中心 `seat = {x: desk.x + DESK_W/2, y: desk.y + 33}`。
- 使う廊下はY座標から自動判定（`desk.y>500→WALK_Y4 / >390→WALK_Y3 / >260→WALK_Y2 / それ以外→WALK_Y`）。
- 机は「カイロ風・斜め立体机」（天面＋前面＋モニタ＋落ち影）で描画。`pc:` 指定でモニタの種類が変わる（→ `04`）。

## 吹き出し文言（状態別）
```js
WORK_BUBBLES = ["なるほど！","できた！","ふむふむ","むむ…","ヨシ！","要確認"]; // 作業中

```

## 部屋を自分用に変えるときのチェックリスト
1. `ROOMS` の `name` を書き換える（数・位置はそのままでOK）。
2. その部屋に置くメンバーの `room` を同じ名前に。
3. メンバーの `desk.x/y` を部屋矩形の内側に収める（上3段は高さ78 or 110、下2段は72）。
4. `door` は所属列に合わせて `DOORS` の値（53/158/263）から選ぶ。
