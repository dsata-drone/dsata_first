# 03. インフルエンサー戦略（主担当: ルナ / 承認: ジン）

作成: 2026-07-19 / 根拠調査: `調査資料/インフルエンサー調査.md`（2026-07-19実施・実在確認済み）

## 戦略の骨子
**「大物1本狙いではなく、3つの層に小さく分散して型を見つける」**

調査からの重要な発見: **「子ども向けプログラミング×ドローン」を専門に発信する個人インフルエンサーは現状ほぼ空白地帯**。
競合が少ないため、中規模の発信者と深く組むだけで領域の第一想起を取れる可能性がある。

## 3つの層とアプローチ
### 層1: 保護者リーチ（Instagram系・小規模から開始）
| 候補 | 内容 | 規模感（要最新値確認） |
|---|---|---|
| アキ（元小学校教諭のママ向け発信） | 小学生ママ向け学習情報 | 約12.6万 |
| れんママ（@krn_world_mom） | 知育・育脳 | 約10.1万 |
| Calon | 知育・おうち教育 | 約8.6万 |
| せでぃあ | 電子工作×子どもプログラミング×親目線 | 不明（合致度は最高クラス） |

- アプローチ: **ギフティング（機体貸与＋カリキュラム提供）から開始**。有償化は反応を見て判断
- 期待する型: 「おうちでドローンプログラミング体験」リール

### 層2: 教育の権威・大型（YouTube系・中期で1本）
| 候補 | 内容 | 規模感 |
|---|---|---|
| 市岡元気（GENKI LABO） | 科学実験。企業タイアップ実績多数（日立ハイテク等） | 110万人超 |
| 葉一（とある男が授業をしてみた） | 授業動画。Z会コラボ実績 | 約210万人 |
| タツナミシュウイチ | ゲーム/テック×教育の権威 | 不明 |

- アプローチ: 実績（層1の成果・導入事例）が溜まってから企画書つきで打診。「編隊飛行を科学する」など先方の型に乗る企画
- 予算規模が大きいため**社長決裁事項**

### 層3: 教員・学校リーチ（X/YouTube・信頼構築）
| 候補 | 内容 | 備考 |
|---|---|---|
| 坂本良晶（さる先生） | 教員向けICT活用 | 現Canva Japan所属のため受託可否の確認が最初 |
| えざわ先生・ささT | 現役/元教員のYouTube発信 | 学校導入文脈を語れる |
| 高梨智樹 | ドローンレーサー | 「テクノロジーが子どもの可能性を開く」ストーリーが理念と合致 |

- アプローチ: PR案件ではなく**授業体験会への招待・共同イベント**から。教員は服務上の炎上リスクがあるため「教員にシェアさせる」設計は避ける（SNS戦略の調査所見と整合）

## 参考にするタイアップの型（事例確認済み）
1. **アンバサダー制度型**: 「子供の科学」×市岡元気、Canva「Teacher Canvassador」→ 単発PRより長期の「ALUX公認〇〇」設計
2. **共同キャンペーン型**: Z会×葉一
3. **ママ目線レビュー型**: 知育アプリ×ママインフルエンサーのInstagram PR

## 実行手順（初月）
1. ルナ: 層1候補4名の最新フォロワー数・PR受付窓口・直近投稿を確認しリスト更新
2. ルナ: ギフティング打診文テンプレ作成（製品概要・貸与条件・「PR」表記の依頼を明記）
3. ゲン: ギフティング原価（貸与機・送料）の枠を設定
4. ジン: 打診リストの最終確認 → **社長承認後に送付開始**
5. タクミ: 貸与機の整備・安全マニュアル同梱の準備

## 必守ルール
- **ステマ規制**: すべてのタイアップ・ギフティング投稿に「PR」明示を契約条件にする（責任は当社側に課される）
- 未成年の子どもが映る場合の同意取得はSNS戦略の肖像権ルールに準拠
- 教育効果の誇大表現をインフルエンサー任せにしない（投稿前の表現チェックを当社で実施）

## KPI（3層モデル準拠）
- 先行: 打診数（初月10件）、ギフティング成立数（3件）
- 中間: タイアップ投稿の総リーチ・保存数
- 成果: 経由の問い合わせ・EC売上（UTM/クーポンコードで識別）
