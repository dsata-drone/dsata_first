# 戦略KPI設計（ゲン担当）

作成: 2026-07-19 / 対象: WEB・SNS・インフルエンサーの3戦略共通

## 設計方針
- **架空の数字を目標にしない**: 現時点で計測基盤が未接続のため、初月は「計測できる状態を作る」こと自体をKPIにする
- 各施策は「先行指標（自分で動かせる数）→ 中間指標（反応）→ 成果指標（商談・売上）」の3層で追う
- 計測できない施策は原則やらない（やる場合は手動記録のルールを決めてから）

## 3層KPIモデル
| 層 | WEB | SNS | インフルエンサー |
|---|---|---|---|
| 先行（自分で動かせる） | 記事・事例の公開本数 / 構造化データ実装ページ数 | 投稿本数 / ショート動画本数 | 打診数 / 商談数 |
| 中間（反応） | 検索順位（定点20本）/ CTR / AI検索引用回数 | 再生数 / フォロワー / 保存数 | タイアップ成立数 / 総リーチ |
| 成果（事業） | 問い合わせ数 / 資料DL数 | プロフィール→サイト遷移数 | 経由の問い合わせ・EC売上 |

## 計測基盤（レイの実装タスクに対応）
| ツール | 用途 | 状態 |
|---|---|---|
| Google Search Console | 検索順位・CTR・インデックス状況 | 未接続（要: サイト所有権確認） |
| GA4 | 流入元別のサイト行動・CV計測 | 未接続（要: タグ設置） |
| 定点プロンプト台帳 | 検索可視性の週次定点観測 | **稼働中**（初回 7/19 計測済み） |
| SNS各媒体のインサイト | 投稿反応の記録 | アカウント開設後 |
| UTMパラメータ規約 | SNS/インフルエンサー経由の流入識別 | 未策定（レイが規約案を作る） |

## 月次レビュー（ジンが実施）
- 毎月末に3層KPIを1枚に集計し、`strategy/月次レビュー_YYYY-MM.md` として記録
- 「先行指標は達成したが中間が動かない」施策は型を変える。「中間まで動いて成果が出ない」施策は導線を疑う

## 予算の考え方（初期値・社長承認事項）
- 初月は**アカウント開設・計測整備・コンテンツ制作のみ**（広告費0円で開始可能）
- インフルエンサータイアップは「ギフティング（製品貸与）→ 成果があれば有償」の2段階
- 有償タイアップ・広告出稿の単価と月額上限は、初月の実測が出た段階でゲンが起案し社長が決裁
